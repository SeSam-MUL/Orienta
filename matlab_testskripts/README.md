# MATLAB test scripts (MTEX reference)

> **⚠️ Status: work in progress — to be finished.**

Original MATLAB/MTEX scripts that the Python [`analysis/`](../analysis/) module was
ported from. They are kept as a reference for the EBSD post-processing workflow
(grain-size, KAM/GOS, texture/ODF, recrystallization). They are **not** required
to run Orienta — use the maintained Python equivalents in `analysis/` instead.
