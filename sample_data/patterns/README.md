# EBSD example datasets

The three example EBSD measurements are distributed **separately** from the
source repository because of their size (~800 MB total). **Download them and put
the files in this folder** (`sample_data/patterns/`).

Where to get them:

- **GitHub:** the latest **Release** of this repository → *Assets*.
- **Zenodo:** archived release, concept DOI **10.5281/zenodo.21021937** →
  `sample_data/patterns/` inside the archive.

| File | Sample | Notes |
|------|--------|-------|
| `SampleB_Al-extrusion.h5oina` | Al extrusion alloy | Oxford H5OINA, includes EDS |
| `Scan1_indexed.h5` | Scan 1 | pre-indexed dataset |
| `AA7050_R_area1.h5oina` | AA7050 (Al-Zn-Mg-Cu) | 39×136, small & fast to index |

Then load any of them via **EBSD Viewer → Load Data**.
